Dự án C Math Demo

Dự án phần mềm mã nguồn mở mẫu minh họa quy trình tạo tài liệu và cấp phép cho ứng dụng tính toán C.

Mục tiêu
Hướng dẫn cấu trúc tài liệu cơ bản của một dự án mã nguồn mở.
Cung cấp mã nguồn C đơn giản và quy trình biên dịch.

Hướng dẫn Cài đặt và Sử dụng
- Yêu cầu
Đã cài trình biên dịch GCC (MinGW trên Windows hoặc GCC trên Linux).

- Biên dịch và Chạy chương trình
